# GLOW UP – אפליקציית הגלואו אפ האישית

מאמן אישי בכיס: טיפוח עור, שיער ותספורות, כושר ויציבה, תזונה, סטייל ולבוש, שינה ושגרה – עם תוכנית אישית, משימות יומיות, מעקב התקדמות ומאמן שעונה על שאלות.

פרויקט נפרד לחלוטין בתיקייה `glow-up-app/` – לא נוגע במשחק `open-world-game/`.

## הרצה

אין צורך בהתקנה או בבנייה – רק שרת קבצים סטטי:

```sh
cd glow-up-app
./tests/serve.sh          # או: python3 -m http.server 8090
# ואז לפתוח http://localhost:8090
```

עובד במחשב ובטלפון. אפשר להעלות את התיקייה לכל אחסון סטטי (GitHub Pages, Netlify וכו׳) ולהוסיף למסך הבית כאפליקציה (PWA, עובדת גם בלי אינטרנט – חוץ ממאמן ה-AI).

## מסלול השינוי ("השינוי שלי")

גלואו אפ אמיתי – מערכת שמשנה גוף ומראה, לא רשימת תרגילים:

- **יעדים מחושבים** (נוסחת Mifflin-St Jeor + רמת פעילות): קלוריות, חלבון, שומן, פחמימות וצעדים – לחיטוב (גירעון מתון של ~20%), בניית מסה (עודף קטן), ריקומפוזיציה או שדרוג פנים. רצפות בטיחות (1500/1200 קק״ל), בלי גירעון כש-BMI נמוך.
- **בדיקה שבועית אדפטיבית**: משווה את ממוצע המשקל של השבוע לשבוע הקודם ומעדכנת את היעדים (±150 קק״ל) – התוכנית מתקנת את עצמה לפי התוצאות.
- **לוח זמנים משוער** למשקל היעד.
- **אימון עם עומס הדרגתי** (חדר כושר / בית עם משקולות / בלי ציוד, 3 או 4 אימונים בשבוע): לכל תרגיל משקל × חזרות מדויקים; כשכל הסטים מגיעים לקצה הטווח – המשקל עולה (או מעבר לתרגיל קשה יותר); תקיעות → שבוע הקלה. שיאים והתקדמות לכל תרגיל.
- **יומן אוכל** עם 43 מזונות נפוצים, רישום ידני, ו**תפריט לדוגמה שמחושב ליעדים שלך** (שינוי כמויות אוטומטי) שאפשר להוסיף ליומן בלחיצה.
- **פרוטוקול פנים** לפי סדר השפעה: אחוז שומן, נפיחות, עור (כולל רטינואיד למבוגרים), תספורת, זקן, גבות, יציבה, חיוך ועיניים – ורשימת "מה לא עובד" (מיואינג, מכשירי לסת, יוגה לפנים).
- **מדדים**: משקל יומי + גרף ממוצע 7 ימים, היקף מותניים, צעדים, ותמונות לפני/אחרי פרטיות.
- המשימות נכנסות אוטומטית לתוכנית היומית, והמאמן מכיר את היעדים.
- **מתחת לגיל 18**: אותה מערכת אימון ופנים, אבל בלי יעד קלוריות ובלי גירעון – הגוף עוד גדל.

## המאמן – AI אמיתי או מדריך מובנה (בכנות)

- **בלי מפתח API** המאמן עובד במצב **"מדריך מובנה"** – מנוע מבוסס כללים שמבין נושאים נפוצים ועונה מתוך התוכן של האפליקציה והנתונים שלך (משימות, ארון, תוכנית). הממשק מציג במפורש "מצב מדריך (ללא AI)".
- **עם מפתח API של Anthropic** (הגדרות › מאמן AI) המאמן משתמש ב-**Claude** (`claude-opus-5-5`) דרך ה-SDK הרשמי (`vendor/anthropic-sdk.mjs`, גרסה 1.2.0). התשובות מוזרמות בזמן אמת, עם הנחיות בטיחות (התאמה לגיל, בלי דיאטות לבני נוער, בלי הבטחות לשינוי מבנה עצמות, הפניה לרופא/ער״ן כשצריך). מופעל גם `fallbacks: "default"` (חזרה אוטומטית למודל אחר אם הבקשה נדחית).
- המפתח נשמר רק בדפדפן, הבקשות יוצאות ישירות ל-`api.anthropic.com`, ונשלח רק טקסט – אף פעם לא תמונות. אפשר לכבות שיתוף פרופיל.

## פרטיות

אין שרת ואין חשבון. כל המידע ב-`localStorage`, תמונות ב-IndexedDB – במכשיר בלבד. אפשר לייצא, לייבא ולמחוק הכל מההגדרות.

## בדיקות

```sh
./tests/serve.sh &              # שרת על 8090
node tests/smoke.mjs            # בדיקת קצה-לקצה ב-Chromium (Playwright)
```

הבדיקה עוברת על כל השלבים: הרשמה, הדרכה, משימות ושמירה אחרי רענון, תוכניות, שגרה, טיפוח, שיער, ארון וסטייליסט, תרגילים ואימון מודרך, תזונה, מאמן, התקדמות, תקציב, הגדרות, ניווט, רוחב טלפון ומחיקת מידע.

## מבנה

```
glow-up-app/
  index.html, manifest.webmanifest, sw.js, icon.svg
  css/app.css               מערכת העיצוב (שחור/לבן/סגול + ניאון, כהה ובהיר)
  js/main.js                ניווט, תפריט תחתון, ערכת נושא
  js/store.js               שמירת נתונים (localStorage + IndexedDB)
  js/plan.js                מנוע התוכנית והמשימות
  js/figure.js              הדגמות תרגילים מונפשות (SVG)
  js/coach-local.js         מדריך מובנה (ללא AI)
  js/coach-ai.js            Claude (עם מפתח של המשתמש)
  js/transform.js           מנוע מסלול השינוי (יעדים, התאמה שבועית, עומס הדרגתי, תפריט)
  js/tour.js, reminders.js, routines.js
  js/data/                  תוכן: תרגילים, מדריכים, תספורות, ארוחות, סטייל, מוצרים, טיפים
  js/screens/               המסכים
  vendor/                   Anthropic SDK (bundle) + רישיון
  tests/                    בדיקת קצה-לקצה
```

המידע באפליקציה כללי ואינו תחליף לייעוץ רפואי, תזונתי או מקצועי אישי.
